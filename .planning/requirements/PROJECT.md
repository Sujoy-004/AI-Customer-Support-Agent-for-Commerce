# Project: Kasparro Agentic Commerce Hackathon

## 1. Overview
**Goal:** Build AI agents that discover, explain, and sell better on Shopify.
**Context:** Shopping is shifting from "search-and-browse" to "ask-and-decide."

## 2. Architectural Tooling (Mandatory)
The following frameworks and protocols MUST be used:
- **[GSD (Get Shit Done)](https://github.com/gsd-build/get-shit-done)**: Implementation protocol (Phased waves & Gates).
- **[Superpowers](https://github.com/obra/superpowers)**: Subagent orchestration and capability framework.
- **[Context7](https://github.com/upstash/context7)**: Latent context management and stability.
- **[Antigravity Skills](https://github.com/sickn33/antigravity-awesome-skills)**: Expert skill injection library.
- **[Obsidian Skills](https://github.com/kepano/obsidian-skills)**: Brain structure and inter-linked documentation.

## 3. Problem Statements (Tracks)
1.  **AI Shopping Agent (Discovery)**: Conversational search and recommendation.
2.  **AI-Assisted Checkout Recovery**: Real-time intervention for abandoned carts.
3.  **AI Checkout Copilot**: Reducing friction during the checkout flow.
4.  **AI Customer Support Agent**: Order status, returns, exchanges resolution. *(Selected)*
5.  **AI Representation Optimizer (Advanced)**: Store diagnostics for AI-agent perception.

## 4. Mandatory Deliverables
- **[PRODUCT_DOC.md](./PRODUCT_DOC.md)**: Problem, user journey, decisions, tradeoffs (High-Fidelity).
- **[TECHNICAL_DOC.md](./TECHNICAL_DOC.md)**: Architecture, AI/Deterministic boundary, failure handling.
- **[DECISION_LOG.md](../DECISION_LOG.md)**: Running list of "Considered X, chose Y, because Z."
- **README.md**: Setup instructions and overview.
- **Demo Video**: 3–5 minute narrated recording.

- Technical Execution & Architecture (25%)
- Product Experience (20%)
- Business Relevance (15%)
- Originality & Insight (15%)
