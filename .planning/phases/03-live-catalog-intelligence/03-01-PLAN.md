# Phase 3 Plan 01: Catalog Service Layer

## Objective
Build the core catalog service with type definitions, realistic mock data, product/variant resolution, and inventory stock checking — following the existing PolicyService patterns exactly.

## Tasks

<task>
Extend src/services/types.ts with Product, Variant, StockInfo, CatalogQuery, ProductOption, ProductImage types
</task>

<task>
Create src/services/mockCatalogData.ts with 3-5 realistic Shopify products including multi-option variants (Size, Color, Material), mix of in/out-of-stock, and low stock items
</task>

<task>
Define CatalogDataSource interface for swappable data sources (mock vs live Shopify API)
</task>

<task>
Create src/services/catalogService.ts with methods: loadProducts, getProduct, searchProducts, checkStock, checkVariantByOptions, clearCache. Use 2-min catalog cache TTL, never cache inventory.
</task>

<task>
Write comprehensive unit tests (src/services/catalogService.test.ts) covering: product loading, caching behavior, search/filter, stock checking (in-stock, out-of-stock, low-stock), variant resolution by options, cache clearing
</task>
