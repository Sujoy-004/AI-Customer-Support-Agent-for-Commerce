# Phase 3 Plan 02: Catalog Integration & Intent Detection

## Objective
Wire the CatalogService into the ChatWidget response pipeline with a CatalogIntentDetector that recognizes product-related queries (sizing, stock, availability) and routes them to the catalog service for real-time answers.

## Tasks

<task>
Create src/services/catalogIntentDetector.ts that classifies queries as: product search, variant availability, stock check, sizing inquiry, or general catalog browsing — using keyword patterns from OffTopicDetector's ON_TOPIC_KEYWORDS
</task>

<task>
Integrate CatalogService + CatalogIntentDetector into shopify-widget/src/ChatWidget.ts: detect catalog intents before mock response fallback, route to catalog service, format product/stock responses
</task>

<task>
Handle edge cases: product not found (graceful "sorry, we don't carry that"), ambiguous option matching, out-of-stock with alternative suggestions
</task>

<task>
Write integration tests covering: catalog intent detection, ChatWidget catalog response pipeline, out-of-stock vs in-stock response formatting
</task>

<task>
End-to-end test: "Do you have this in medium blue?" → variant resolved → stock checked → formatted response returned
</task>

## Verification
- Integration tests pass
- Catalog intent queries correctly routed to catalog service
- Non-catalog queries fall through to existing policy flow
- Out-of-stock items display accurate "not available" message (not hallucinated)
- Missing products display graceful "not found" response

## Success Criteria
- User asking "Do you have X in size Y?" gets real-time stock answer from catalog service
- User asking about unavailable product receives accurate "out of stock" or "not found" response
- Existing policy grounding and off-topic refusal flows remain unchanged for non-catalog queries
