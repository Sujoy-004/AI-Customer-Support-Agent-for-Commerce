Conversation State Machine

All possible session states and valid transitions

🟡 IDLE
Session initialized. Agent greeting shown. Waiting for first customer message.
→ VERIFYING on first message
🔵 VERIFYING
Collecting Order # + email. Identity check against Shopify in progress.
→ CLASSIFYING on success
→ VERIFY_FAILED on 3 bad attempts
🔵 CLASSIFYING
LLM parses intent. Routing to one of 4 workflow tools + escalation check.
→ ORDER_LOOKUP
→ RETURN_FLOW
→ PRODUCT_QUERY
→ POLICY_QUERY
→ ESCALATING if unknown
🟢 ORDER_LOOKUP
Fetching live order + fulfillment data from Shopify. Composing tracking response.
→ RESOLVED on success
→ API_ERROR on Shopify fail
→ CLASSIFYING on follow-up
🟢 RETURN_FLOW
Checking return eligibility → triggering Shopify return → confirming label.
→ RESOLVED on label sent
→ ESCALATING if ineligible edge case
→ API_ERROR on Shopify fail
🟢 PRODUCT_QUERY
Querying live catalog + inventory. Grounded answer composed by LLM.
→ RESOLVED on answer
→ CLASSIFYING on follow-up
🟢 POLICY_QUERY
Vector search on policy store. RAG context injected. LLM composes answer.
→ RESOLVED on answer
→ CLASSIFYING on follow-up
🟠 ESCALATING
Trigger fired. Packaging context transcript + order data for human agent queue.
→ HUMAN_PENDING on package sent
🟠 HUMAN_PENDING
Agent read-only. Customer shown wait time. Waiting for human to claim session.
→ HUMAN_ACTIVE on claim
✅ RESOLVED
Query answered. CSAT rating shown. Session logged. Metrics updated.
→ CLASSIFYING on new question
→ CLOSED on session end
🔴 API_ERROR
Shopify/LLM call failed after retries. Informing customer, triggering escalation.
→ ESCALATING always
⬛ CLOSED
Session ended. All data anonymized and logged. Widget collapsed.
→ IDLE on new session
